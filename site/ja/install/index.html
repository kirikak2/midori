インストールガイド

パソコンのブラウザ（Chrome または Edge）だけで、MIDoRI をボードに書き込めます。 開発環境やコマンドの操作は要りません。所要時間は 10 分ほどです。

このブラウザでは書き込めません。パソコンの Google Chrome か Microsoft Edge で、このページを開き直してください。 Safari・Firefox と、スマートフォン・タブレットのブラウザは USB 機器に直接つなぐ機能（Web Serial）を持っていません。

準備するもの

対応ボード

M5Stack CoreS3 / CoreS3 SE、M5Stack Tab5、Elecrow CrowPanel Advanced 7 インチ（ESP32-P4）、Freenove ESP32-S3 のいずれか。

USB-C ケーブル

データ通信ができるもの。充電専用のケーブルではボードが見つかりません。うまくいかないときは、まずケーブルを替えてみてください。

パソコンとブラウザ

Windows / macOS / Linux / ChromeOS のパソコンで、Google Chrome か Microsoft Edge。

microSD カード（なくても可）

サンプルのスクリプトやプラグインを使うときに。32 GB 以下で、FAT32 でフォーマットしたもの。

まだリリースが公開されていません。リリースが出ると、ここから書き込めるようになります。 それまではソースからビルドしてください（README）。

ボードを選ぶ

USB の使い方を選ぶ

ボードの USB ポートを何に使うかで、書き込むファームウェアが変わります。あとから入れ直して変えることもできます。

Tab5 は USB-A ポートがいつも「MIDI 機器をつなぐ」側なので、USB-C をパソコン用にしても MIDI 機器は USB-A につなげます。Tab5 はこの組み合わせだけを配布しています。

このボードは USB ポートの回路が 1 つなので、MIDI 機器をつなぐ使い方とパソコンにつなぐ使い方は同時にはできません。

どちらの使い方でも、MIDI に使うのは「USB 2.0」と書かれた USB-C ポートです。「UART」のポートは書き込み専用です。

パソコンとつなぐ

まずボードを選んでください。

本体の USB-C ポートとパソコンをケーブルでつなぎます。

MIDoRI を入れ直すとき（2 回目以降）は、MIDoRI が USB ポートを MIDI に使っているため、そのままでは見つかりません。 先にダウンロードモードにしてください: 本体側面のリセットボタンを約 3 秒長押しし、内部の緑色の LED が点いたら離します。 工場出荷時のファームウェアからなら、この操作は要りません。

本体の USB-C ポート（USB-A ではない方）とパソコンをケーブルでつなぎます。

MIDoRI を入れ直すとき（2 回目以降）は、MIDoRI が USB-C を MIDI に使っているため、そのままでは見つかりません。 先にダウンロードモードにしてください: リセットボタンを長押しし、緑色の LED が点滅し始めたら離します。

「UART」と書かれた USB-C ポートとパソコンをケーブルでつなぎます。ボタンの操作は要りません。

Windows でボードが見つからないときは、WCH の CH343 ドライバを入れてください（このポートは CH343 という USB シリアル変換チップです）。

「COM」と書かれた USB-C ポートとパソコンをケーブルでつなぎます。ふつうはボタンの操作は要りません。

書き込みが始まらないときは、BOOT ボタンを押したまま RESET を押して離し、続けて BOOT を離してからやり直してください。

書き込む

このブラウザは対応していません（Chrome か Edge を使ってください）。 安全な接続（https）でページを開いてください。
  1. ボタンを押すと、ブラウザがポートの一覧を出します。ボードを選んで「接続」を押します （「USB JTAG/serial debug unit」など「USB Single Serial」などの名前で出ます）。
  2. 「Install MIDoRI」を押し、「Erase device」にチェックを入れて次へ進みます（初回は必ず。保存済みの設定が消えます）。
  3. 書き込みには数分かかります。終わるまでケーブルを抜かないでください。
  4. ダウンロードモードで書き込んだときは、終わったらリセットボタンを 1 回押して起動してください。

microSD カードを用意する（なくても可）

サンプルのスクリプトと、コード・アルペジオなどの MIDI フィルタやパネルを入れたプラグインを、そのまま SD カードに入れられる形で配布しています。

  1. SD カード用のファイル（zip）をダウンロードして展開します。
  2. FAT32 でフォーマットした microSD カードのいちばん上（ルート）に、展開した中身をすべてコピーします（plugins フォルダごと）。
  3. カードをボードに差して、電源を入れ直します。

使ってみる

起動すると Home 画面が出ます。タイルから各画面へ移動します。

  • MIDI Devices … つないだ機器どうしを、マス目をタップして結ぶ（キーボード → シンセ など）
  • Keys / Pads / Knobs / XYPad … 画面で演奏する
  • Tempo / Sequencer … テンポを決めて、パターンを組んで再生する
  • Scripts … SD カードのスクリプトを選んで動かす

画面がないので、シリアルコンソール（115200 bps）から load /sd/ファイル名.rb でスクリプトを動かします。 詳しくは README を見てください。

自分で Ruby のスクリプトを書くときは、サンプルと ドキュメントが出発点になります。

うまくいかないとき

ポートの一覧にボードが出てこない
  • データ通信ができるケーブルか確かめてください（充電専用のものが多く出回っています）。
  • パソコンの別の USB ポートにつなぐか、USB ハブを外して直接つないでみてください。
  • MIDoRI を入れ直すときは、先にダウンロードモードにする必要があります（手順 3）。
  • Windows で CrowPanel / Freenove が出ないときは、CH343 のドライバを入れてください。
「Failed to connect」と出る・途中で止まる
  • ダウンロードモードにしてから、もう一度試してください。
  • Arduino IDE やシリアルモニタなど、同じポートを使っているアプリを閉じてください。
  • ブラウザのタブを再読み込みしてからやり直してください。
書き込んだのに画面が真っ暗
  • リセットボタンを 1 回押してください（ダウンロードモードで書き込んだときは自動では起動しません）。
  • 「Erase device」にチェックを入れて、もう一度書き込んでください。
  • 選んだボードが手元のボードと合っているか確かめてください。
元のファームウェアに戻したい

M5Stack の製品は M5Stack の書き込みツール（M5Burner）で、Elecrow / Freenove の製品は各社の配布するファームウェアで元に戻せます。 MIDoRI を消すだけでよければ、どのボードも各社のツールで書き込み直せば上書きされます。

コマンドで書き込みたい（開発者向け）

リリースのページから、ボードとモードに合った .bin（全体を 1 つにまとめたイメージ）をダウンロードし、esptool で 0x0 に書き込みます。

pip install esptool
python -m esptool --chip esp32s3 write_flash 0x0 midori-v1.0.0-m5stack-host.bin   # Tab5 / CrowPanel は --chip esp32p4

ソースからのビルドは README を見てください。
