部品

空いたところをクリックしてパッド / ノブを置く。ドラッグで入れ替え、矢印キーで隣と入れ替え、Delete で削除。

空いたセルをドラッグして部品を置く。部品はドラッグで移動、選んだ部品の右下の角をドラッグで大きさを変える（矢印キーで移動、Shift + 矢印で大きさ、Delete で削除）。

プレビューは実機と同じ描画で、そのまま操作できます。部品の変更は動かしたまま反映します（ノブの値はそのまま）。デバイス・パート・ルート・メニュー・レイアウトのタイトルを変えると作り直します。

MIDoRI 実機（USB-C / Web Serial）

プロジェクトを実機の /sd/<名前>.rb（Scripts 画面から実行）か /app.rb（電源を入れたときに実行）に保存します。開けるのはデザイナーで作ったファイルだけです。

デバイス

      

      
    

    

      
AMY パート（Tab5）

      

      
      
Keys などでパートを鳴らすときは、デバイスに AMY を足して、そのパートのチャンネルで送ります。Envelope の送り先にもなります。

    

    

      
ルート（MIDI.route）

      

      
      
受けた MIDI を C で別のデバイスへ流します（MIDI Thru）。Clock は Tempo のクロック（MIDI::Clock）。そのボードに無いデバイスのルートは飛ばします。

    

    

      
Home のメニュー

      

      
外した画面は Home に出ず、UI.show でも開けません（UI.menu(hide:)）。Home と Scripts は常に出ます。スクリプトが終われば元に戻ります。
